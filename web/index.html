Character, label and options
Character picker

Added and opened palettes stay for this session, up to 16; adding one with a name already added replaces it. A palette lists each printable ASCII character at most once.

Art stamps stay in this session only, up to 16 stamps and 1,000,000 cells in total. Drag a stamp to preview; release to place it.

Tables, trees and flowcharts

A table takes one row per line, split into cells at the separator; quotes are not special. A tree takes one item per line, indented with spaces under its parent. A flowchart takes Mermaid flowchart or graph text, such as graph LR; A --> B. Make stamp saves the drawing as an art stamp and chooses Stamp art, ready to place.

Layers

Up to 16 layers. A space shows the layers below it. Every layer shares the frames, their timing and the size: adding, moving or deleting frames changes every layer, and a new size or frame count needs Merge layers first. Opening a file, converting a picture or video and restoring recovery replace every layer, locked ones too; Undo brings them back. Merge layers keeps what is shown and drops hidden layers. Saved JSON keeps the layers; copied text, saved text and the player show what is visible. A locked layer keeps its characters, keys and name until it is unlocked; frame changes that apply to every layer still apply to it. Show only the chosen layer changes the stage alone, not what is copied, saved or exported.

Keyframes

Keys move, stretch and turn the layer chosen in Layers over the frames. Set a value at the selected frame; between 2 keys it moves by the easing of the earlier one.

Recovery is off on each page load. Enabling it stores applied artwork and timings locally. Unapplied text edits, session stamps and undo history are excluded. Browser clearing or eviction can remove it; save JSON for a separate copy. Another tab changing the saved record stops recovery in this tab.

No canvas, image preview, SVG artwork or Unicode block substitutes. Copy a frame into an editor, use the Rust library in your own program or play a saved project in a terminal.
The JSON project keeps frames and their durations. The standalone HTML player renders the same characters as text. Images, videos and the camera are accepted only as conversion inputs.
